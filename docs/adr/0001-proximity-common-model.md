# ADR 0001. 근접 모델을 장소별 배치 모델에서 배치 없는 공통 모델로 바꾼다

- 상태: 채택
- 날짜: 2026-11-10
- 결정: [#252](https://github.com/capstone-itda/nearpilot-server/issues/252)의 A안 (decision PR #257). [#40](https://github.com/capstone-itda/nearpilot-server/issues/40) B안의 장소별 모델 파일을 대체한다.
- 구현: PR #269, `specs/core-proximity-common-model/spec.md`
- 지운 spec: `specs/core-proximity-estimator/spec.md`(#130), `specs/core-proximity-model-fit/spec.md`(#176). 지우기 전 내용은 `git show 4ea47e2:specs/core-proximity-estimator/spec.md`처럼 읽는다.

## 이전 모델

- 모델 파일은 장소마다 하나였다 (`{model_root}/{place_id}/{model_version}.json`). 설정의 `[proximity.models]` 표가 장소마다 버전을 골랐다.
- 파일은 기기마다 좌표, 기기 앞 위치와 경로손실 값 `A`, `n`, `sigma`를 담았다. "어느 기기 앞도 아님"의 값 `none_rssi`, `none_sigma`도 담았다.
- 적합은 장소 배치 파일(`config/layouts/`)과 그 장소의 수집 회차로 기기별 값을 구했다.
- 전체 상태는 장소의 모든 `trusted` 기기였다. 모델 파일에 없는 `trusted` 기기가 있으면 `posterior`가 `ModelMismatchError`로 실패했다.
- 보정 버전은 모델 파일 안의 값이었다.

## 왜 바꿨나

- 소유자가 기기를 등록하고 신뢰해도, 누군가 좌표를 재고 장소별 모델을 만들기 전에는 근접 지정을 쓸 수 없었다.
- 장소에 기기를 하나 더 놓으면 그 장소의 근접 지정이 멈췄다.
- 보고를 멈춘 기기도 상태로 남았다.
- 기기마다 안테나와 케이스가 달라서 생기는 RSSI 차이를 기기별 `A`로 흡수했다. 좌표 없이 공통 값을 쓰려면 이 차이를 다른 방법으로 지워야 했다.

## 바꾼 것

- 공통 모델 파일 하나를 모든 장소가 쓴다 (`{model_root}/{model_version}.json`, 설정 `[proximity] model_version`). 파일에는 장소 ID, 기기 ID, 좌표, 기기별 파라미터가 없다.
- 관측 모델은 "앞 기기만 튄다"다. 앞 기기, 다른 기기, 어느 기기 앞도 아님의 정규분포 셋(공통 값 여섯 개)만 쓴다.
- 전체 상태는 근접 참여 기기다. 근접 참여 기기는 최근 구간 `anchor_recent_sec` 안에 보고를 보낸 `trusted` 기기다. 참여하지 않는 기기는 명시 지정으로만 쓴다.
- 기기별 RSSI 차이는 자동 영점으로 지운다. 근접 추정이 장소의 관측으로 기기마다 찾고, DB의 `auto_zero`(마이그레이션 `0013`)에 개정으로 저장한다. 보정 버전은 자동 영점의 개정 번호다.
- 자동 영점이 없는 기기는 보수적 사후확률로 임계값을 본다. 보수적 사후확률은 그 기기의 영점을 공통 폭 Δ 안에서 가장 불리하게 가정하고 다시 계산한 값이다. Δ는 적합이 찾은 자동 영점에서 정해 모델 파일에 쓴다.
- 적합은 배치 파일 없이 장소별 수집 회차로 공통 값을 구한다. 배치 파일과 그것을 읽는 코드를 지웠다.

## 그대로인 것

- 사후확률 출력(후보 확률을 다시 정규화하지 않음), 근접 임계값, HMM 전이, 우도 온도 보정
- 명시 지정과 거리 선택자의 판정

## 결과

- 소유자의 일은 기기 등록과 신뢰뿐이다.
- 기기가 1~2대인 장소는 자동 영점을 찾지 못한다. 방문자가 늘 같은 기기 앞에 있으면 그 기기는 자동 영점 표본을 얻지 못한다.
- 그런 기기도 신호가 보수적 사후확률로 임계값을 넘을 만큼 강하면 근접 지정을 쓸 수 있다. 애매한 거리에서는 `ASK`다.
- 지금 모델 파일(`synthetic-2.json`)은 합성 값이다. 실제 정확도는 지표 8로 평가하기 전까지 검증하지 않았다. 지표 8이 통과하지 못할 때 할 일은 미결이다 (#258).
- 옛 합성 모델 파일 `synthetic-1.json`은 판정 기록이 참조할 수 있어서 남긴다. 서버는 읽지 않는다.
