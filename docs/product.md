## 문제

- 주변 기기를 쓰려면 전용 앱과 장소별 가입이 번거롭다.
- 사용자가 기기를 잘못 선택한다.
- 여러 사용자가 서로 간섭한다.

## 사용자

| 사용자 | 제품과 만나는 지점 |
|---|---|
| 방문자 | Android 앱으로 계정·비콘을 한 번 등록하고 백그라운드 송출. 장소별 등록 없이 AI 호스트로 조회·사용·해제 |
| 소유자·설치자 | Android 앱에서 접근 승인·거부, 대시보드에서 노드 신뢰·장소·정책 설정과 FAULT 복구 |
| AI 호스트 | Claude·ChatGPT·Gemini가 같은 MCP URL·도구를 사용. 토큰으로 연결하며 사용자 ID를 입력하거나 전달받지 않음 |
| ESP32 노드 | 기능 발표·RSSI·안전 상태·실행 결과를 MQTT로 보고하고 서버 명령을 실행 |

## 제품이 하는 일

NearPilot은 AI 호스트의 자연어 요청을 실제 주변 기기의 사용으로 연결하는 인증·판정 서버다.

- 입력: AI 호스트가 전달한 사용자의 요청
- 출력: 주변 기기의 실행, 또는 실행하지 않은 판정과 사유
- 약속: 아래 원칙을 지킨다.

## 원칙

- 계정·비콘 관측·접근 정책·점유 상태를 서버가 결정론적으로 검사하고, 허가한 요청만 노드가 실행한다.
- LLM이나 호스트 확인 UI는 허가의 근거가 아니다.

## 범위

### 포함

- 서버: MCP, 앱·대시보드 REST, 모니터링 WebSocket, MQTT 연동, 근접 추정, 정책·승인, 점유·해제, 기록·평가
- 연동 계약: Android UI·ESP32 펌웨어·대시보드 프런트엔드는 별도 구현이며 서버는 연동 계약을 제공한다.

### 제외

- iOS
- 실제 잠금장치·고보안 출입문·게이트
- 강한 단말 인증
- LLM을 이용한 서버 판정
