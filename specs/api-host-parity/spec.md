# FR-10·NFR-09 도구 6개의 호스트 동등성 테스트

- 담당: eunji719 (판정)
- 요구사항: FR-10, NFR-09
- 따르는 결정: 없음

## 1. 왜

- `test_FR10_호스트_이름과_상관없이_같은_응답`은 `request_use` 하나와 `clientInfo.name`만 바꿔 본다. 나머지 도구 5개와 호스트마다 다른 HTTP 헤더(`User-Agent`)는 확인하지 않는다. 서버가 호스트 이름을 읽는 코드가 어느 도구에 생겨도 지금 테스트는 알려주지 못한다 (NFR-09 "호스트를 바꿀 때 서버를 고치지 않는다").

## 2. 무엇

- 입력: 호스트 3종(`claude`, `chatgpt`, `gemini`)이 보낸 초기화와 도구 호출. 호스트마다 `clientInfo`와 `User-Agent`가 다르다.
- 출력: 도구 목록과 도구 6개의 응답, 서비스(`CoreService`)가 받은 호출
- 바뀌는 상태: 없다. 서비스는 fake 다.
- 약속:
  - 도구 목록(이름, 설명, 입력 스키마)은 호스트와 관계없이 같다.
  - 도구 6개는 호스트와 관계없이 같은 응답을 준다.
  - 서비스가 받는 호출도 호스트와 관계없이 같다. `UseRequest.host_kind`는 호스트와 관계없이 같은 값이다.

## 3. 제약

- 코드를 고치지 않는다. 실패하면 코드의 결함이다. 테스트를 맞추지 않고 담당자에게 알린다.
- 호스트 이름은 판정에 쓰이지 않는다 (FR-10, NFR-07).
