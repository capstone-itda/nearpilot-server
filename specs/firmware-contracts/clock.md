# 펌웨어 spec의 시각 동기화 항목

- 관련 요구사항: FR-05, FR-06, FR-07, NFR-12다.
- 근거: requirements.md §1.2와 architecture.md §5 MQTT 6·7절이다.

## 지킬 계약

서버와 기기는 폐쇄망 안의 시각원으로 동기화한다. 외부 인터넷을 필수로 두지 않는다.
최대 시각 오차는 기기별로 실측한다. 검증 전 값은 미설정이다.
동기화 전, 시각원 변경 뒤와 오차 한도 준수를 확인하지 못한 동안 새 명령을 `CLOCK_UNVERIFIED`로 거부한다.
서버도 검증 전 기기의 시각 기반 실행과 안전 확인을 차단한다.

## spec에서 정할 내용

| 항목 | 담당자가 기록할 내용 |
|---|---|
| 동기화 | 배포 환경의 폐쇄망 시각원에 연결하는 방법과 시작 절차다 |
| 재동기화 | 재동기화 간격과 시각원 단절·변경 뒤의 동작이다 |
| 신뢰 상태 | 시각 신뢰를 확인하거나 무효로 만드는 조건과 내부 상태 관리 방법이다 |
| 측정 | 기기별 최대 오차를 측정하는 방법, 측정 조건과 검증 근거다 |
| 내부 설정 | 펌웨어 내부 시간 값의 이름, 단위, 범위와 적용 방법이다 |

방법과 수치는 아직 정하지 않았다. 담당자가 선택하고 검증한 내용을 구현 spec에 기록한다.
시각원을 어디에 배포할지는 설치 환경을 확인한다. 이 문서는 노트북이나 별도 서버를 선택하지 않는다.
서버·공용 설정의 이름과 적용 방법은 현재 docs의 미결 범위를 따른다. 펌웨어 spec만으로 확정하지 않는다.

## spec에 담을 검증

1. 재부팅과 재접속 뒤 동기화와 기기별 최대 오차를 확인한다.
2. 장시간 동작, 시각원 단절과 시계 보정 때 오차 한도를 확인한다.
3. 시각 신뢰를 확인하기 전 새 명령을 거부하는지 확인한다.
4. 물리 동작 직전 대상 연결과 최대 오차를 고려한 유효 시간을 다시 검사하는지 확인한다.
5. 시뮬레이터의 같은 PC 시계 가정을 실제 기기의 검증 근거로 쓰지 않는지 확인한다.
